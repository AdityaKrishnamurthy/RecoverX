# Impeccable UI/UX Skill

## Principles
1. Fintech Ops Density: Clear typographic hierarchy, tabular numeric figures, zero decorative clutter.
2. Semantic State System:
   - Amber: At-risk / diagnosing
   - Red: Escalated / stopped / critical
   - Green: Recovered / kept promise
   - Blue: Intervening / scheduled
   - Neutral: Base background, borders, subtle text
3. Auditability: Every visual metric connects to a verifiable data event.
4. State Completeness: Always include loading, empty, and error states for every view.
